 Tehran House Price Prediction | پیش‌بینی قیمت خانه در تهران

A machine learning project for exploring Tehran's housing market and predicting house prices using Python.

پروژه‌ای برای تحلیل داده‌های بازار مسکن تهران و پیش‌بینی قیمت خانه با استفاده از پایتون و الگوریتم‌های یادگیری ماشین.


 Overview

This project explores a real estate dataset containing information about houses in Tehran. The goal is to analyze housing features, explore relationships between variables, and build regression models to estimate house prices.

This is a learning project developed as part of my journey into Data Science and Machine Learning.

 Dataset

The dataset is based on Tehran real estate listings from Divar.

**Source:** [Kaggle - Tehran Divar House Price Prediction](https://www.kaggle.com/code/soheiltehranipour/tehran-divar-ir-house-price-prediction)

 Features

The dataset includes information such as:

- Area
- Number of rooms
- Parking availability
- Warehouse availability
- Elevator availability
- Address
- House price
- Price in USD

 Technologies and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

 Project Workflow

1. Data loading and initial inspection
2. Exploratory Data Analysis (EDA)
3. Data cleaning and preprocessing
4. Data visualization and correlation analysis
5. Feature preparation
6. Training and comparing regression models
7. Model evaluation and cross-validation

 Models Explored

- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor

 Current Status

This project is an ongoing learning project. Data quality checks, preprocessing, model validation, and evaluation will be improved in future updates.

 Limitations

The dataset may contain outdated listings, invalid values, and other data quality issues. Model results should not be interpreted as reliable estimates of current market prices.

This project is intended for educational purposes only.
